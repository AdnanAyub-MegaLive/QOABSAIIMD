## Brand & Style

This design system delivers an executive-grade operational command center for live social streaming administration. The target audience comprises operations directors, trust & safety moderators, community managers, and platform financial analysts who require maximum informational density, swift cognitive processing, and sustained visual comfort across 8-hour shift cycles.

The visual direction combines crisp corporate modernism with deep maritime architectural anchors:
- **Structural Dualism:** An immersive, high-contrast dark teal navigational foundation grounded against an ultra-clean, low-glare light workspace canvas.
- **Precision Instrumentation:** Border-defined cards, high-legibility tabular density, structured metadata grids, and explicit visual hierarchies designed for zero misclicks during critical moderation actions.
- **Controlled Telemetry:** A restrained emerald primary accent provides intentional focal points, while strictly disciplined semantic accents categorize live stream metrics, platform currencies, and enforcement statuses.

## Colors

The palette balances ergonomic data monitoring with unmistakable operational signal clarity.

### Primary & Functional Neutrals
- **Primary Emerald (`#059669` / `#10B981`):** Applied exclusively to confirmed operational actions, active toggle states, positive telemetry, verified creator flags, and revenue triggers.
- **Deep Marine (`#0A1C20` base, `#0F292E` surface):** Houses persistent navigation, top-level administrative switches, and global search contexts to visually isolate platform controls from workspace data.
- **Workspace Surfaces (`#F8FAFB` canvas, `#FFFFFF` cards, `#F1F5F7` active row hover):** Eliminates glare while establishing razor-sharp separation between layout containers.
- **Slate Text & Boundaries (`#0F172A` primary text, `#475569` secondary text, `#94A3B8` muted captions, `#E2E8F0` structural borders, `#CBD5E1` active borders):** Delivers WCAG AAA contrast for numerical and data-heavy tables.

### Streaming Currency & Telemetry Tokens
- **Coins (Platform Tip Token):** Amber / Gold (`#F59E0B` fill, `#D97706` text/border, `#FEF3C7` container).
- **Diamonds (Creator Redeemable Units):** Cyan / Blue (`#06B6D4` fill, `#0891B2` text/border, `#CFFAFE` container).
- **Fiat / Gross Merchandise Value (USD):** Emerald (`#10B981` fill, `#047857` text/border, `#D1FAE5` container).
- **Live State / Broadcast Active:** Crimson Pulse (`#EF4444` dot/badge, `#FEE2E2` tint).
- **Flagged / Audit Needed:** Violet Warning (`#8B5CF6` fill, `#EDE9FE` container).

## Typography

The type hierarchy prioritizes vertical scanability, visual rhythm, and numerical parity.

- **Primary Typeface (Hanken Grotesk):** Selected for clean geometric discipline with humanist apertures. Delivers authoritative section titles, executive KPI totals, and readable user IDs without stroke-width fatigue.
- **Data & Micro UI Typeface (Geist):** Powers status tags, platform telemetry units, currency indicators, table column headers, and administrative logs. Its tabular figure alignment guarantees that dynamically fluctuating streaming metrics (e.g., bitrates, concurrent viewers, coin velocities) align vertically without layout jitter.
- **Capitalization Rules:** All `label-sm` elements and table headers are styled uppercase with `letterSpacing: 0.03em` for clean delineation against standard data cells.

## Layout & Spacing

The layout operates on a fixed-sidebar, fluid-canvas architecture calibrated for dense operational monitors (1440px to 2560px), while collapsing predictably down to tablet diagnostics.

### Layout Mechanics
- **Primary Shell:** Fixed left rail navigation at `260px` width (collapsible to an icon-only `68px` rail). Global utility header fixed at `56px` height.
- **Workspace Canvas:** Fluid container with max-width bounding at `1920px` to maintain optimal data scanning width; margins scale from `1rem` on compact viewports to `2rem` on wide desktop environments.
- **Data Grid System:** 12-column responsive layout engine utilizing `1.5rem` gutters for card metrics, with sub-grids converting into 1-, 2-, 4-, or 6-column arrangements.
- **Table Density Standards:** Standard table rows maintain a locked `44px` height; dense view mode toggles to `36px` row height for high-throughput moderation queues. Element interior margins use `space-sm` (`0.5rem`) for compact telemetry clusters and `space-lg` (`1rem`) for primary card bodies.

## Elevation & Depth

Visual hierarchy is achieved through precise mechanical surface tiers, crisp structural outlines, and subtle tinted ambient shadows. Heavy blurs and aggressive drops are excluded to prioritize clarity.

### Elevation Levels
- **Canvas Base (`#F8FAFB`):** Ground level. No shadow.
- **Level 1 (Cards, Panel Containers, Data Tables):** Pure white background (`#FFFFFF`) framed by a persistent `1px` solid border in `#E2E8F0`. Shadow: `0 1px 2px 0 rgba(15, 41, 46, 0.04), 0 1px 3px 0 rgba(15, 41, 46, 0.02)`.
- **Level 2 (Hover States, Interactive Rows, Filter Popovers):** White surface (`#FFFFFF`) with `#CBD5E1` border boundary. Shadow: `0 4px 6px -1px rgba(15, 41, 46, 0.06), 0 2px 4px -2px rgba(15, 41, 46, 0.04)`.
- **Level 3 (Action Modals, Critical Enforcement Flyouts, Currency Drawers):** White surface (`#FFFFFF`) flanked by `#CBD5E1` edge definition. Shadow: `0 10px 15px -3px rgba(15, 41, 46, 0.08), 0 4px 6px -4px rgba(15, 41, 46, 0.04)`.
- **Dark Navigation Rail (`#0A1C20` to `#0F292E`):** Distinct lateral anchor with an inset right border `1px solid rgba(255, 255, 255, 0.08)` to eliminate the need for heavy casting shadows onto the workspace.

## Shapes

The design system standardizes on precise, moderate corner geometries (`roundedness: 2`) to balance contemporary software polish with strict operational geometry.

- **Micro Controls & Badges (6px / `rounded-sm`):** Status indicators, currency tags, pagination pills, and compact table buttons.
- **Standard Controls & Inputs (8px / `rounded-md`):** Input fields, select dropdowns, standard buttons, and tab switchers.
- **Cards & Data Modules (10px / `rounded-lg`):** Metric panels, video preview wrappers, filter bars, and modular queue boards.
- **Overlays & Dialogs (12px / `rounded-xl`):** Enforcement confirmation dialogs, inspector sheets, and creator settlement modals.
- **Avatars & Live Dots:** Fully circular (`rounded-full`) to contrast against rectangular data infrastructure.

## Components

### Buttons
- **Primary Operational:** Filled `#059669`, text `#FFFFFF`, 8px radius, height `36px`. Hover: `#047857`. Focus: ring 2px `#10B981` offset 2px.
- **Secondary / Shell:** Outlined `1px solid #CBD5E1`, background `#FFFFFF`, text `#0F172A`. Hover: background `#F1F5F7`, border `#94A3B8`.
- **Destructive Moderation:** Filled `#DC2626`, text `#FFFFFF`. Used strictly for ban, stream kill, and account termination actions.
- **Ghost Utility:** Borderless, text `#475569`. Hover: background `#F1F5F7`, text `#0F172A`.

### Status Badges & Currency Indicators
- **Base Geometry:** Height `22px`, horizontal padding `8px`, corner radius `6px`, font `label-sm` (`Geist`).
- **Live Stream Active:** Pulse indicator (6px red circle `#EF4444` with subtle ping animation) accompanied by `#DC2626` text over `#FEE2E2` background.
- **Coin Value Indicator:** Amber container (`#FEF3C7`), text `#B45309`, coin icon prefix, display tabular monospaced integer.
- **Diamond Value Indicator:** Cyan container (`#CFFAFE`), text `#0E7490`, diamond icon prefix, display tabular monospaced integer.
- **USD / Revenue Pill:** Emerald container (`#D1FAE5`), text `#047857`, currency prefix, formatted decimal string.

### Tables & Data Grids
- **Header:** Background `#F8FAFB`, height `36px`, text `label-sm` uppercase `#64748B`, bottom border `1px solid #CBD5E1`.
- **Data Rows:** Background `#FFFFFF`, height `44px` (regular) or `36px` (compact), border-bottom `1px solid #F1F5F7`. Active hover state `#F8FAFB`.
- **Cell Content:** Left-align standard text (`body-md`), right-align all numeric values and currencies (`data-mono`). Pin quick-action moderation buttons to the frozen right column.

### Inputs & Filters
- **Text Inputs:** Height `36px`, background `#FFFFFF`, border `1px solid #CBD5E1`, text `#0F172A`, placeholder `#94A3B8`, radius `8px`. Active focus shifts border to `#059669` with `0 0 0 1px #059669`.
- **Filter Bars:** Integrated multi-select chip rows with clear inline counters (`Active: 4`), quick reset action, and instant debounced lookup.

### Cards & Metric Panels
- **Structure:** Crisp white card (`#FFFFFF`), `1px solid #E2E8F0`, padding `1.25rem`.
- **Metric Layout:** Top row displays title in `label-md` `#64748B` alongside context icon; main metric in `headline-lg` `#0F172A` with geist mono figures; bottom row displays delta trend tag (+14.2% emerald or -3.1% rose) against comparison period.

### Video Preview & Moderation Canvas
- 16:9 and 9:16 aspect ratio containers with `#0A1C20` backing canvas. Includes low-latency playback indicators, stream health telemetry overlay (FPS, resolution, audio bitrate in `data-mono`), and single-click quick sanction triggers (Warning, Mute, Force Terminate).
