# Updated staff permissions

Accounts & Permissions uses the shared permission catalogue, so these keys appear automatically as checkboxes:

| Key | Enforced operation |
| --- | --- |
| rules.levels | Publish Account Level / XP thresholds, including removal |
| rules.hierarchy | Save reporting limits, draft salary targets and Country Head designation |
| rules.currency | Change currency, withdrawal/exchange and related valuation policy |
| video.gifts | Create/edit live gift artwork, prices and XP |
| video.rewards | Change live target rewards and settlement configuration |

Each requires its group's View permission. Existing rules.manage now covers profit-split/host rules; video.manage remains live moderation. Existing staff do not automatically receive the newly separated permissions. Platform Super Admin retains all permissions. Managers can grant only permissions they hold, and descendants retain the existing parent-permission intersection.

Upload permission labels explicitly describe Props, Gifts, role artwork, User Tags and Profile BG; these remain governed by uploads.manage. Special ID labels describe Standard/VIP/SVIP assignment. Events Portal retains its separate account and permission system; no ineffective Events checkbox is added here. Mobile application roles are distinct from portal staff permissions.
